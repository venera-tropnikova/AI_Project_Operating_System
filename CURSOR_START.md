# CURSOR_START

## Перед началом

1.  Ознакомься с `Governance/CONSTITUTION.md` (канон проекта).
2.  Прочитай `Standards/README.md`.
3.  Соблюдай все стандарты из папки `Standards`.
4.  При конфликте документов приоритет у `Governance/CONSTITUTION.md`.
5.  Не меняй архитектуру без согласования.
6.  Не изменяй несвязанные модули.
7.  Предлагай решение кратко.
8.  После одобрения --- выполняй.

------------------------------------------------------------------------

## Принципы

-   User First.
-   Простые решения лучше сложных.
-   Минимум токенов.
-   Минимум изменений.
-   Не дублировать код.
-   Не ломать существующий функционал.

------------------------------------------------------------------------

## Формат ответа

1.  Анализ (2--3 строки).
2.  План.
3.  Ждать подтверждение.
4.  После выполнения --- краткий отчёт.

------------------------------------------------------------------------
