# Границы доступа AI POS

Этот документ задаёт обязательные границы доступа для агентов и инструментов
при работе с AI Project Operating System.

## Разрешённые области доступа

1. открытый проект;
2. системное хранилище AI POS;
3. файл или папка, явно выбранные пользователем;
4. точный путь, явно указанный пользователем.

## Запрещено без отдельного разрешения

- рекурсивный поиск по дискам;
- просмотр Desktop, Documents, Downloads и облачных папок;
- использование `Get-ChildItem -Recurse`, `Path.rglob`, `os.walk` вне разрешённых областей;
- использование найденных файлов в анализе.
