# AI Project Operating System (AI POS)

Общий фундамент для всех AI-проектов.

## Быстрый запуск (без Cursor)

### Windows — основной способ

1. Откройте папку AI POS.
2. Дважды щёлкните: **start_ai_pos.cmd**

Откроется приложение в браузере. Cursor и терминал не нужны.  
Python 3 пока является системным требованием.

Папку AI POS можно переносить на другой диск — запуск остаётся из корня этой папки.

### Windows — необязательный ярлык

Ярлык на рабочем столе **не обязателен**.

При желании:

- один раз запустите `create_ai_pos_shortcut.cmd` — на рабочем столе появится ярлык **AI POS**, который запускает систему без окна терминала;
- либо создайте обычный ярлык Windows на файл **start_ai_pos.cmd** и назовите его по-русски.

После переноса папки AI POS ярлык на рабочем столе нужно создать заново.

### macOS / Linux

```bash
chmod +x start_ai_pos.sh
./start_ai_pos.sh
```

Откроется браузер: http://127.0.0.1:8080/  
Остановка: Ctrl+C.

### Примечание

Достаточно одного файла запуска — **start_ai_pos.cmd**.  
Имена файлов запуска намеренно записаны латиницей: так они не портятся при копировании и упаковке папки AI POS. Русское название остаётся у ярлыка на рабочем столе.
