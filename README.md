# AI Project Operating System (AI POS)

Общий фундамент для всех AI-проектов.

## Быстрый запуск (без Cursor)

### Windows — основной способ

1. Откройте папку AI POS.
2. Дважды щёлкните: **Запустить AI POS.cmd**

Откроется приложение в браузере. Cursor и терминал не нужны.  
Python 3 пока является системным требованием.

Папку AI POS можно переносить на другой диск — запуск остаётся из корня этой папки.

### Windows — необязательный ярлык

Ярлык на рабочем столе **не обязателен**.

При желании:

- создайте обычный ярлык Windows на файл **Запустить AI POS.cmd**, или
- один раз запустите `create_ai_pos_shortcut.cmd`.

После переноса папки AI POS ярлык на рабочем столе нужно создать заново.

### Windows — разработчик

`start_ai_pos.cmd` — запуск с видимым окном лога (отладка).

### macOS / Linux

```bash
chmod +x start_ai_pos.sh
./start_ai_pos.sh
```

Откроется браузер: http://127.0.0.1:8080/  
Остановка: Ctrl+C.

### Примечание

Служебные имена пользователю знать не нужно — достаточно **Запустить AI POS.cmd**.
