# Standards

## Назначение

В этой папке находятся рабочие стандарты проекта AI POS. Все новые
изменения должны соответствовать этим документам.

------------------------------------------------------------------------

## Порядок приоритета

1.  `Governance/CONSTITUTION.md`
2.  DEVELOPMENT_STANDARD.md
3.  DESIGN_SYSTEM.md
4.  UX_RULES.md
5.  UI_COMPONENTS.md
6.  BRAND_GUIDE.md
7.  DOCUMENT_STANDARD.md
8.  NAMING_STANDARD.md
9.  PROMPT_STANDARD.md
10. REVIEW_STANDARD.md

Brand Consistency и Simplicity **не** являются принципами Конституции; они живут в Standards (см. ниже).

------------------------------------------------------------------------

## Для чего каждый файл

### DEVELOPMENT_STANDARD.md

Правила разработки и внесения изменений.

### DESIGN_SYSTEM.md

Цвета, типографика, карточки, кнопки, общая визуальная система.

### UX_RULES.md

Правила поведения интерфейса и принцип User First.  
Предметный стандарт **Simplicity** описан здесь (`## Simplicity`).

### UI_COMPONENTS.md

Единые требования к элементам интерфейса.

### BRAND_GUIDE.md

Логотип, фирменные цвета и правила использования бренда (**Brand Consistency** на уровне Standards).  
Операционное правило Cursor по эталону иконки: `.cursor/rules/ai-pos-brand.mdc` (не заменяет этот файл как предметный стандарт).

### DOCUMENT_STANDARD.md

Оформление документации проекта.

### NAMING_STANDARD.md

Правила именования файлов, переменных, функций и компонентов.

### PROMPT_STANDARD.md

Стандарт написания промптов для ИИ.

### REVIEW_STANDARD.md

Правила проверки кода перед завершением задачи.

------------------------------------------------------------------------

## Правило

Перед созданием нового стандарта сначала проверить существующие. Если
правило уже описано --- дополнить существующий документ, а не создавать
новый.
