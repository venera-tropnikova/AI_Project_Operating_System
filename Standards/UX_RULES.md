# UX Rules

## User First

Every screen must answer: - What is happening? - What should I do next?

## Simplicity

One primary action per screen.

## Readability

Prefer whitespace over decorations.

## Feedback

Every action should clearly report: - Success - Warning - Error

## Consistency

Identical controls behave identically everywhere.

## Что видит пользователь

Пользователь видит только то, что требует его участия, или итог завершённого действия.

Служебные процессы, PowerShell, Python, API, JSON, пути и внутренние проверки пользователю не показываются.

Длительные операции сопровождаются только ненавязчивым индикатором выполнения.

Запрос разрешения формулируется человеческим языком.

После завершения показываются:

1. результат (успех или ошибка);
2. что было сделано;
3. если нужно — следующее действие пользователя.
